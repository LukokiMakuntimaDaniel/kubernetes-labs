# ☸️ Kubernetes Labs

> "A melhor forma de dominar sistemas complexos é praticar constantemente até que se tornem simples."

Este repositório foi criado para documentar todos os meus exercícios, comandos e projetos práticos com Kubernetes.

Aqui não há apenas teoria — cada conceito é testado em laboratório.

---

## 🎯 Objetivo

* Aprender Kubernetes na prática
* Dominar criação e gestão de clusters
* Trabalhar com Pods, Deployments e Services
* Aplicar networking e segurança
* Criar projetos reais em ambiente containerizado
* Criar um guia pessoal de referência rápida

---

## 🧪 Estrutura

O repositório está dividido em:

* **Basics** → Fundamentos do Kubernetes
* **Workloads** → Pods, Deployments, Jobs
* **Networking** → Services, Ingress, DNS
* **Storage** → Volumes e Persistência
* **Security** → RBAC e permissões
* **Labs** → Exercícios práticos
* **Projects** → Aplicações reais

---

## 🛠 Tecnologias usadas

* Kubernetes (k8s)
* Docker
* kubectl
* YAML
* Helm
* Linux

---

## 🚀 Filosofia

Aprender Kubernetes não é decorar comandos, é entender como sistemas distribuídos pensam.

Este repositório cresce com cada erro, teste e experiência prática.
