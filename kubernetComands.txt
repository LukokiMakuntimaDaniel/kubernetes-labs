kubectl version
Mostra a versão do kubectl e do cluster Kubernetes.

kubectl config get-clusters
Mostra a lista de clusters Kubernetes configurados no teu kubectl.

kubectl config get-contexts
Mostra todos os contextos configurados no kubectl, incluindo clusters, utilizadores e namespaces disponíveis.

kubectl get pods
Lista todos os pods existentes no cluster Kubernetes.

export MY_NAMESPACE=sn-labs-$USERNAME
Cria uma variável de ambiente chamada MY_NAMESPACE e atribui um nome de namespace baseado no utilizador atual.

docker build -t us.icr.io/$MY_NAMESPACE/hello-world:1 . && docker push us.icr.io/$MY_NAMESPACE/hello-world:1
Constrói uma imagem Docker a partir do diretório atual e envia essa imagem para o registry remoto no IBM Cloud Container Registry.

kubectl run hello-world --image us.icr.io/$MY_NAMESPACE/hello-world:1 --overrides='{"spec":{"template":{"spec":{"imagePullSecrets":[{"name":"icr"}]}}}}'
Cria e executa um pod chamado hello-world usando a imagem do IBM Cloud Registry e define credenciais (imagePullSecrets) para permitir o download da imagem.

kubectl get pods -o wide
Lista todos os pods do cluster com informações adicionais como IP, nó onde estão a correr e estado detalhado.

kubectl describe pod hello-world
Mostra informações detalhadas do pod hello-world, incluindo eventos, estado, imagens usadas e possíveis erros.

kubectl delete pod hello-world
Remove o pod hello-world do cluster Kubernetes.

kubectl create -f hello-world-create.yaml
Cria recursos no cluster Kubernetes a partir do ficheiro YAML hello-world-create.yaml.

kubectl apply -f hello-world-apply.yaml
Cria ou atualiza recursos no cluster Kubernetes usando o ficheiro YAML hello-world-apply.yaml.


kubectl get deployments
Lista todos os deployments existentes no cluster Kubernetes.

kubectl expose deployment/hello-world
Cria um Service para expor o deployment hello-world dentro do cluster Kubernetes.

kubectl proxy
Inicia um proxy local que permite acessar a API do Kubernetes através de localhost.
